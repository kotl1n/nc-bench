# NC-Bench-RU: Набор для независимого экспертного ручного ревью

> [!IMPORTANT]
> **Статус релиза**: `draft/unvalidated`
> Все переводы и адаптации прошли автоматическую двухпроходную верификацию, но **до проведения независимого ручного человеческого ревью набор имеет статус предварительного черновика (draft/unvalidated)**.

Всего отобрано для ревью: **180 заданий** (минимум 5 примеров на каждую из 36 категорий всех трёх подмножеств + сложные и спорные случаи).

## Инструкция для независимого ревьюера
При проверке каждой пары EN/RU оценивайте следующие критерии:
1. **Сохранение проверяемого разговорного действия**:
   - Просьба повторить (Repeat) не должна превращаться в просьбу объяснить.
   - Просьба перефразировать (Paraphrase) не должна превращаться в просьбу повторить.
   - Реплики завершения («понял», «ясно», «спасибо») должны сохранять функцию Sequence Closer.
   - Реплики отмены («забудь», «неважно», «отбой») должны сохранять функцию Sequence Abort.
2. **Естественность русского языка**: отсутствие неестественного машинного синтаксиса при сохранении разговорной непринуждённости.
3. **Сохранение фактов и чисел**: точное соответствие числовых значений, единиц измерения и условий задачи.
4. **Отсутствие подсказок**: русский перевод не должен подсказывать тестируемой модели правильный ответ или упрощать исходное затруднение.
